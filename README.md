# 中药材来源鉴别证据

该项目保存送检批次、封签分样、检验方法和签发意见的领域资料。原始观察与方法版本是鉴定证据的一部分，后续复检不得覆盖既有记录。

`domain/contracts.py` 定义样品、检验和意见结构，`fixtures/specimen_chain.json` 是一次脱敏的复检与封签争议记录。项目使用 Python 3.11，可执行 `python -m compileall domain` 检查契约语法。

## 证据链服务

- `domain/registry.py`：方法版本与对照批次的时效登记，回答"某版本/批次在观察当时是否有效"。
- `domain/ledger.py`：`EvidenceChain` 台账。分样保持来源与数量守恒；检验结果按原始数据摘要去重，重复上传不新增检验；签发时复核方法版本与对照材料的当时有效性，封签争议阻止签发；鉴定、复核、签发三人分离；迟到结果只能形成补充意见，已签发结论不可改写；撤销必须留下原因。
- `domain/trace.py`：从最终意见回放到原始留样，列出每次交接、方法依据与冲突证据的处理。

## 运行

- `python replay.py`：回放 fixture 的复检与换标争议，打印完整证据链。
- `pytest`：运行守恒、去重、时效、职责分离、迟到补充、封签拦截与撤销留痕的规则测试。
